# SharpGrit website — premium draft (v2)

This folder is a second, darker design. The original draft in the parent folder (`/workspace/sharpgrit-site/index.html`) is unchanged.

To replace a placeholder photo, keep the same filename and drop your image into `images/`. Recommended: JPEG or WebP, at least 2000 px on the long side. Product photos work best at about 4:3. The hero works best at 16:9 (or wider).
